시스템 개요

이 프로젝트는 클라우드 환경의 공개 리소스를 모니터링하고, Nmap·Amass·CloudEnum 등 다양한 클라우드 스캐닝 도구를 유기적으로 연동하여 자동화된 클라우드 환경 아카이빙을 제공합니다. 사용자가 별도의 스크립트 작성이나 복잡한 설정 없이도 버튼 클릭으로 공개 리소스, Shadow IT 현황을 파악할 수 있도록 설계되었습니다.

스캔 작업은 일회성 방식과 주기적 방식을 모두 지원하며, 사용자가 원하는 스캔 주기를 설정하면 스케줄러가 해당 시점에 자동으로 스캔을 실행합니다. 개별 스캔 결과는 데이터베이스에 보관되며, 웹 대시보드의 타임라인 뷰에서 시간별 변화를 한눈에 확인하실 수 있고, 스냅샷에서 개별 스캔의 결과를 확인할 수 있습니다.

또한, 검출된 리소스는 유형별로 자동 분류되며, 리소스별 상세 리포트로 제공됩니다. 더불어, 사용자가 제공하는 파일 내 정보와 실제 공개된 리소스를 자동으로 교차 검증하여 차이 및 불일치 사항을 식별합니다.

  • 정기 스캔
    - 사용자가 설정한 주기에 따라 클라우드 자산 및 네트워크 리소스를 자동으로 주기 스캔합니다.
  • 수동 스캔
    - IP 또는 도메인 입력과 파일 제공 시 Nmap·Amass·CloudEnum·Nuclei 등 다양한 도구가 연계 실행됩니다.
  • Scan 뷰
    - 현재 스캔 현황을 대시보드 형태로 시각화하여 공개 리소스 상태를 모니터링합니다.
  • Archiving 뷰
    - 스캔 결과를 타임라인, 스냅샷, 리포트 형태로 아카이빙하여 시점별 변화 추적이 가능합니다.
  • Report 뷰
    - 사용자가 선택한 필터에 대해 자동 생성된 상세 리포트를 조회 및 다운로드할 수 있습니다.
